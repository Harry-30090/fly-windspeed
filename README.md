# 風速何mで飛んでしまうか計算機

人が風で飛ばされるために必要な風速を簡易的に計算するWebアプリです。
体重・肩幅・身長を入力することで、理論的な臨界風速（m/s）を求めます。


## 概要

このツールは空気抵抗の式を用いて、風による力が体重（重力）を上回る風速を計算します。

以下の物理モデルに基づいています：

* 空気密度：1.225 kg/m³
* 抗力係数：1.2（人間の平均的な値）
* 重力加速度：9.81 m/s²


## 計算式

風で飛ばされる条件は、風の抗力が体重を超えることです。

使用している式：

$`v = \sqrt{\frac{2mg}{C_d \rho A}}`$


* $`v`$：風速 (m/s)
* $`m`$：体重 (kg)
* $`g`$：重力加速度
* $`C_d`$：抗力係数
* $`\rho`$：空気密度
* $`A`$：正面投影面積（肩幅 × 身長）


## 使い方

1. 体重（kg）を入力
2. 肩幅（m）を入力
3. 身長（m）を入力
4. 「計算」ボタンをクリック

→ 飛ばされるのに必要な風速が表示されます

## ⚠️ 注意

* この計算は非常に単純化されたモデルです
* 実際の状況では以下の要因が影響します：

  * 姿勢（立っている / しゃがむ）
  * 地面との摩擦
  * 風の乱れ（突風など）
  * 服装や持ち物
* 安全性の判断には使用しないでください
